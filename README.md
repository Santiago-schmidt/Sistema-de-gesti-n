Sistema de Gestión para Local de Ropa

Descripción:

    Trabajo Práctico Integrador desarrollado para la materia Programación II de la Tecnicatura Universitaria en Programación (UTN General Pacheco).
  
    El sistema permite administrar la información de un local de ropa mediante una aplicación de consola desarrollada en C++, implementando Programación Orientada a Objetos y persistencia de datos mediante archivos binarios.

Funcionalidades principales:

    Gestión de Categorías
    
    - Alta de categorías
    - Modificación de categorías
    - Baja lógica
    - Listado y búsqueda
    
    Gestión de Productos (Items)
    
    - Alta de productos
    - Modificación de datos
    - Control de stock
    - Baja y recuperación lógica
    - Búsqueda por código
    - Listado por categoría
    - Productos con bajo stock
    
    Gestión de Clientes
    
    - Alta, modificación y baja lógica
    - Búsqueda por ID y DNI
    - Listado de clientes
    
    Gestión de Usuarios
    
    - Administración de usuarios del sistema
    - Control de contraseñas
    - Baja lógica
    - Modificación de datos
    
    Gestión de Ventas
    
    - Registro de ventas
    - Registro de detalle de ventas
    - Consulta de ventas realizadas
    - Anulación de ventas
    
    Informes
    
    - Total recaudado
    - Productos más vendidos
    - Ventas por categoría
    - Clientes con mayor volumen de compras
    - Rendimiento de vendedores
    - Productos con stock crítico y análisis de demanda

Tecnologías utilizadas

    - C++
    - Programación Orientada a Objetos (POO)
    - Archivos binarios (.dat)
    - Code::Blocks
    - Git y GitHub
    
Conceptos aplicados

    - Clases y objetos
    - Encapsulamiento
    - Herencia
    - Polimorfismo
    - Clases abstractas
    - Archivos binarios
    - Memoria dinámica
    - Modularización mediante archivos .h y .cpp
    - Validaciones y manejo de datos
    
Estructura del proyecto

    El sistema se encuentra organizado en múltiples clases que representan las entidades principales del negocio:
    
    - Categoría
    - Item
    - Cliente
    - Usuario
    - Venta
    - DetalleVenta
    
    Cada entidad posee su correspondiente clase de acceso a datos para administrar la persistencia en archivos binarios.
